## Features

- **Hero Section** — Animated introduction with typewriter effect and skill role badges
- **Featured Projects** — Dynamic project showcase with category filtering
- **Gallery Modal** — Full-screen image/video gallery for on-site project work
- **About & Contact** — Personal bio with contact links
- **Smooth Animations** — Framer Motion page transitions and scroll-triggered reveals
- **Responsive** — Fully responsive design for all screen sizes

## Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | Next.js 16, TypeScript |
| **Styling** | Tailwind CSS 4 |
| **Animation** | Framer Motion |
| **Icons** | Lucide React |
| **Deployment** | Vercel |

## Quick Start

```bash
npm install
npm run dev
# Opens at http://localhost:3000
```

## Build

```bash
npm run build
npm start
```
